# 未完

一个非盈利的文章收集网站，用来保存有意思、有温度、值得被重新读到的文字。

网站由管理员人工阅读、整理和收录文章。所有已发布内容均可免费阅读全文；原作者保留著作权，并可通过“认领文章”联系站点确认署名、补充来源、修订内容或申请撤下。

## 当前功能

### 阅读端

- 浏览已发布文章
- 免费阅读完整正文
- 查看作者、来源、分类和编辑按语（如有）
- 通过“认领文章”入口联系站点

### 推荐文章

- 用户注册、登录后可推荐文章
- 首版正文仅支持粘贴纯文本
- 提交内容先进入管理员审核列表，由管理员确认后决定是否公开收录
- 管理员可记录审核状态和备注

### 内容管理

- 管理员可在阅读模式和管理模式之间切换
- 管理员可直接收录文章并保存为草稿
- 收录时只有正文必填；标题、作者与来源、简介和分类均可留空
- 文章网址由系统自动生成
- 管理员可发布或撤下文章
- 管理操作写入审计记录

## 内容原则

- 页面只展示真实收录的文章；尚无内容时展示明确的空状态
- 每篇公开内容都经过人工阅读和选择
- 尽量保留准确的作者署名与原始出处
- 作者信息暂不明确时，可标记为“佚名 / 待认领”
- 涉及侵权或合规问题时，可将相关文章撤下

## 技术栈

- Next.js 15 + React 19
- TypeScript
- PostgreSQL（当前生产环境使用 Neon）
- Vercel 部署
- 服务端会话与基于角色的管理员权限

## 本地启动

1. 安装依赖：

   ```bash
   pnpm install
   ```

2. 复制环境变量模板：

   ```bash
   cp .env.example .env.local
   ```

3. 在 `.env.local` 中配置：

   ```text
   DATABASE_URL=你的 PostgreSQL 连接地址
   AUTH_SECRET=不少于 32 字符的随机字符串
   ```

4. 初始化数据库：

   ```bash
   pnpm db:migrate
   ```

5. 启动开发环境：

   ```bash
   pnpm dev
   ```

6. 在网站注册账号，并将需要管理权限的账号提升为管理员：

   ```bash
   pnpm admin:promote 你的邮箱
   ```

## Vercel 部署

项目连接 GitHub 后由 Vercel 自动部署。生产环境需要配置：

- `DATABASE_URL`
- `AUTH_SECRET`

首次部署前需要对生产数据库执行一次：

```bash
pnpm db:migrate
```

当前正式站点：<https://story-web-lac.vercel.app/>

## 常用命令

```bash
pnpm dev                 # 启动本地开发环境
pnpm build               # 生产构建
pnpm db:migrate          # 执行数据库迁移
pnpm admin:promote 邮箱  # 将注册用户设为管理员
```

`scripts/seed-first-article.mjs` 是早期首篇文章录入脚本，仅在明确需要时手动执行，不属于正常启动流程。
