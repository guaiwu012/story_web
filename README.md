# 未完

原创短篇故事平台的冷启动版本。当前不接入真实支付，管理员可以为注册用户人工授予可审计的全文阅读权限。

## 已完成

- 注册、登录与服务端会话
- 注册用户纯文本投稿
- 管理员审核投稿
- 管理员创建、发布和下架真实作品
- 按作品 ID、类别或全站授予全文权限
- 权限生效时间、到期时间和撤销
- 全文阅读动态用户水印
- 管理操作审计记录
- 空数据库启动，不包含 mock 数据

## 本地启动

1. 复制 `.env.example` 为 `.env.local`，填写 PostgreSQL 连接和不少于 32 字符的随机 `AUTH_SECRET`。
2. 安装依赖：`pnpm install`
3. 初始化数据库：`pnpm db:migrate`
4. 启动：`pnpm dev`
5. 在网站注册第一个账号。
6. 将该账号提升为管理员：`pnpm admin:promote 你的邮箱`

## Vercel

在 Vercel 项目中配置 `DATABASE_URL` 和 `AUTH_SECRET`，部署前对生产数据库执行一次 `pnpm db:migrate`。项目默认将服务端函数放在香港区域。

## 权限模型

- `story_full`：一篇指定作品的全文。
- `category_full`：一个类别中全部已发布作品的全文。
- `platform_full`：全站全部已发布作品的全文。

所有权限都有生效时间、可选到期时间、授予人、备注和撤销记录。未来接入正式支付时，支付成功也生成同一种阅读权益，不需要重写阅读权限判断。
